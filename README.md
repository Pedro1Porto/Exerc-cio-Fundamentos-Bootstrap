# 📚 Exercício Fundamentos Bootstrap

## 🎯 Sobre o Projeto

Este projeto é um exercício prático de **fundamentos do Bootstrap**, focando na criação de interfaces responsivas e modernas com componentes prontos.

## 🛠️ Tecnologias Utilizadas

- **Bootstrap** - Framework CSS para layouts responsivos e componentes estilizados
- **JavaScript (.js)** - Lógica interativa e manipulação do DOM

## ✨ Destaques

### Bootstrap
Utilizamos o **Bootstrap** para construir uma interface limpa, profissional e que se adapta a diferentes tamanhos de tela.

### JavaScript
O arquivo `.js` implementa funcionalidades como:
- **Replace** - Substitui strings para formatação de dados
- **Máscara Operativa** - Formata entrada de usuário em tempo real
